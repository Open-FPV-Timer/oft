Firmware

-
Choose the oft-timer.bin written by tools/uf2.py (not the .uf2). The Timer stores it next to the firmware it is running, checks it, and restarts to try it. Timing stops for the whole update: while the file is stored (about half a minute) the Timer drops Node data, and then it restarts. The new firmware is on trial: if this page cannot reach it, the Timer restarts into the old firmware by itself within about a minute. Keep this page open until it reports the result.

Node firmware

The Timer restarts the Node into its bootloader and writes the file over the same wires the Node link uses (the reset and boot wires must be connected; the wiring test below checks them). Timing stops until the Node is back, a minute or two. If it fails part way, the Node stays silent until an update succeeds: try again, or use the Node's own USB port.
